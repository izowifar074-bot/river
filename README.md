# 梦中暗河

一个单文件网页：用 3D 像素方块（我的世界风格）还原一场梦里的地下河。可以自由旋转、缩放查看整条洞穴，也可以坐上小船，第一人称漂完全程。

直接用浏览器打开 `index.html` 即可，不需要联网，也不依赖任何第三方库。

## 一路经过什么

| 段落 | 景象 |
| --- | --- |
| 幽潭 | 起点。小船停在一口深潭上，潭底是一个发蓝光的竖井。 |
| 拱形水道 | 像大型公路隧道一样的扁拱，约 19 米宽、拱顶离水面约 12 米，船在里面就像车开过山洞隧道。拱顶有一道天然岩缝，缝里的发光苔藓一盏接一盏，像隧道灯。 |
| 第一处潜流 | 隧道中段，拱顶压进水里，整段河道没入水下，潜过去后隧道继续。 |
| 第二处潜流 | 隧道尽头，拱顶再次沉入水中。 |
| 峡谷 | 两侧石壁笔直平整，相距约 37 米，高约 120 米，光照不到，抬头只看见零星的萤光。 |
| 第三处潜流 | 一段很长的水下通道，通往洞厅。 |
| 地下湖洞厅 | 约 150 米宽、50 米高的洞厅，中央是地下湖。穹顶布满萤火虫般的光点；湖心立着一根石柱，岸边有石笋、紫水晶晶洞和一层层发光的石坝水池。 |

潜流两旁藏着十来条灌满水的狭窄小洞，尽头有发光的洞穴珍珠。从岩石外面看，这些水下通道是一条条半透明的蓝色“水脉”。

全部是天然溶洞地貌，没有人工痕迹；唯一的外来物是做梦的人坐的那条船。

## 操作

- **自由视角**：拖动旋转，滚轮缩放，右键或双指平移，双击岩壁飞过去。从岩石外面看时，靠近你的那一侧洞壁会自动隐去，像剖开的模型。
- **船上视角**：点「开始漂流」，船沿河道前进，途中会潜水、上浮，底部会出现梦境旁白。拖动环顾四周，滚轮或双指调整视野。
- 底部的纵剖面就是航线：蓝色下凹处是要潜水的地方，点击或拖动可以跳到任意位置。
- 快捷键：空格 播放/暂停，`V` 切换视角，`1`–`5` 切换预设地点。
- 右上角可以切换 1×/2×/4× 速度和全屏。

## 实现

- 所有内容都在 `index.html` 里，打开时按固定随机种子现场生成：约 584×160×176 个方块的洞穴和 16×16 像素贴图。
- 只用原版方块能做到的效果：像素贴图（最近邻采样）、0–15 级方块光照的洪水填充、平滑光照和环境光遮蔽、方向面明暗、发光方块、半透明流动的水、距离雾和水下蓝雾。没有泛光、倒影、粒子等后期特效。
- 直接用浏览器自带的 WebGL1 绘制，兼容较老的浏览器和手机。
